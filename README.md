## 介绍
一个基于浏览器的像素风格合成工具，你可以导入 Minecraft 像素材质，自由摆放、调整高度和阴影，生成具有立体感的平面图像作品。现已支持像素字、特效、自定义背景和旋转等功能。

## 功能特点
- 支持上传 16×16、32×32、64×64 的像素材质，材质面板可预览和删除
- 拖拽移动、多选（Ctrl+点击）、复制粘贴、撤销/重做（Ctrl+Z / Ctrl+Y）
- **方向键微调**：选中方块后，按方向键移动1px，Shift+方向键移动10px
- **吸附对齐**：按住 Shift 拖拽时自动吸附到相邻方块边缘，并显示参考线
- **批量修改**：多选方块后，调整大小、高度、旋转角度、特效会统一应用到所有选中项
- **自定义画布**：宽度最大 1200px，高度不限，可保存最多5个常用尺寸预设
- **背景模式**：纯色 / 透明 / 自定义背景（可导入图片，调整比例和位置，刷新后保留）
- **网格覆盖层**：可开关的半透明网格，方便对齐摆放
- **深色模式**：一键切换暗色主题，保护眼睛
- **自动保存草稿**：关闭或刷新页面时自动保存当前画布状态，下次打开自动恢复
- **导出预览**：导出前弹窗预览图片，显示像素尺寸，确认后再下载
- **快捷键面板**：点击 `?` 查看所有操作快捷键
- **性能优化**：方块数量超过200时自动降低拖拽时的阴影渲染，保证流畅度
- **独立图片特效**：模糊、对比度、亮度、色调、透明度；阴影与特效联动
- **像素字**：支持 Minecraft 字体，自定义颜色、粗体、斜体、删除线、透明度、模糊度，继承全局阴影和旋转
- **自定义背景**：导入图片作为背景，可调节比例和位置，刷新页面后仍保留
- **旋转功能**：参数面板可设置 0-360° 旋转，支持多选批量旋转
- **图层管理**：左侧图层面板按高度分层，显示缩略图或文字，可拖拽交换层级、隐藏/显示

## 使用方法
1. 打开网页，点击“选择文件”上传你的像素材质
2. 在右侧材质面板中点击选择想要使用的材质
3. 点击“添加到画布”或双击材质，方块会出现在画布中央
4. 调整大小、高度、旋转角度、光源角和阴影长度
5. 用鼠标拖拽方块，配合 Shift 吸附，Ctrl 多选
6. 使用方向键微调位置
7. 在“特效”面板中调整方块的模糊、对比度、亮度、色调、透明度
8. 在“文本”区输入文字，设置颜色、粗体、斜体、删除线，点击“添加文本”生成像素字
9. 点击“导出PNG”保存作品

|--------|------|
| Ctrl+Z | 撤销 |

## 技术实现
- HTML5 Canvas + CSS + 原生JavaScript，无任何第三方框架
- 所有操作均在浏览器本地完成，无需网络请求，无数据上传
- 像素渲染通过imageSmoothingEnabled = false保证清晰
- 草稿（包括自定义背景、特效、文本等）自动保存至localStorage，完整复原
