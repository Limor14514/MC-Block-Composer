##介绍
一个基于浏览器的像素风格合成工具，你可以导入Minecraft像素材质，自由摆放、调整高度和阴影，生成具有立体感的平面图像作品。

## 功能特点
- 支持上传 16×16、32×32、64×64 的像素材质
- 拖拽移动、多选（Ctrl）、复制粘贴、撤销/重做（Ctrl+Z / Ctrl+Y）
- 自定义画布尺寸（宽度最大 900px，高度不限），可保存最多 5 个常用尺寸预设
- 背景可选纯色或透明（暂不支持自定义背景图）
- 通过光源角度和阴影长度实时控制投影方向与距离
- 可导出透明图像或带背景的图像

## 使用方法
1. 打开网页，点击“选择文件”上传你的像素材质
2. 在右侧材质面板中点击选择想要使用的材质
3. 点击“添加到画布”或双击材质，方块会出现在画布中央
4. 调整大小、高度、光源角和阴影长度
5. 用鼠标拖拽方块，配合 Shift 对齐，Ctrl 多选
6. 点击“导出透明PNG”或“导出带背景”保存作品

## 技术实现
- HTML5 Canvas+CSS+原生JavaScript，无任何第三方框架
- 所有操作均在浏览器本地完成，无需网络请求，无数据上传
