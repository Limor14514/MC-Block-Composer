## 介绍
一个基于浏览器的像素风格合成工具，你可以导入 Minecraft 像素材质，自由摆放、调整高度和阴影，生成具有立体感的平面图像作品。

## 功能特点
- 支持上传 16×16、32×32、64×64 的像素材质，材质面板可预览和删除
- 拖拽移动、多选（Ctrl+点击）、复制粘贴、撤销/重做（Ctrl+Z / Ctrl+Y）
- **方向键微调**：选中方块后，按方向键移动1px，Shift+方向键移动10px
- **吸附对齐**：按住 Shift 拖拽时自动吸附到相邻方块边缘，并显示参考线
- **批量修改**：多选方块后，调整大小或高度会统一应用到所有选中项
- **自定义画布**：宽度最大 900px，高度不限，可保存最多5个常用尺寸预设
- **背景模式**：纯色 / 透明 / 棋盘格（棋盘格颜色随背景色变化）
- **网格覆盖层**：可开关的半透明网格，方便对齐摆放
- **深色模式**：一键切换暗色主题，保护眼睛
- **自动保存草稿**：关闭或刷新页面时自动保存当前画布状态，下次打开自动恢复
- **导出预览**：导出前弹窗预览图片，确认后再下载
- **快捷键面板**：点击 `?` 查看所有操作快捷键
- **性能优化**：方块数量超过200时自动降低拖拽时的阴影渲染，保证流畅度

## 使用方法
1. 打开网页，点击“选择文件”上传你的像素材质
2. 在右侧材质面板中点击选择想要使用的材质
3. 点击“添加到画布”或双击材质，方块会出现在画布中央
4. 调整大小、高度、光源角和阴影长度
5. 用鼠标拖拽方块，配合 Shift 吸附，Ctrl 多选
6. 使用方向键微调位置，点击“导出透明PNG”或“导出带背景”保存作品

## 快捷键速查
| 快捷键 | 功能 |
|--------|------|
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |
| Ctrl+C | 复制选中方块 |
| Ctrl+V | 粘贴方块 |
| Delete / Backspace | 删除选中方块 |
| 方向键 | 微调移动 1px |
| Shift+方向键 | 微调移动 10px |
| Shift+拖拽 | 吸附对齐 |
| Ctrl+点击 | 多选/取消多选 |

## 技术实现
- HTML5 Canvas+CSS+原生JavaScript，无任何第三方框架
- 所有操作均在浏览器本地完成，无需网络请求，无数据上传
- - 使用 requestAnimationFrame 优化渲染
  - - 草稿自动保存至 localStorage，页面恢复后完整复原

（当前及支持PC端使用）
